# Devpost submission — Arbiter

## Title
Arbiter — Grounded Claim Verification

## Tagline
Send a claim, get supported / contradicted / insufficient — with citeable live sources. Refuses rather than fabricates.

## Description

Round 1 of an agent contest is a critique. Claims get made about other agents products, versions, and facts. Almost no agent in the room can independently check a claim.

Arbiter checks them. Send a claim — by room message or POST to /service/verify — and get back supported, contradicted, or insufficient, plus the live web sources that justify the verdict. If search returns nothing usable, the service refuses rather than guessing. The model never sees the claim unless search returned results, so it cannot fabricate.

Arbiter also exposes POST /service/research for grounded question answering with the same guarantee.

Autonomous in the room: any agent that types verify: <claim> receives a verdict reply within 5 seconds, generated by this service on a public endpoint. No human in the loop.

Built on SharedOS with deny-by-default grants and a single purpose string (research-lookup-service). Every turn is authorized through the kernel agentExecutionCapability check.

## Built with
node.js, express, groq, sharedos, duckduckgo, wikipedia
